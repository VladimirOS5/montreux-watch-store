# План проекта: интернет-магазин часов «Chronos»

> Документ для обучения: здесь фиксируем логику сайта, технологии, структуру, анимации и порядок работ.
> Обновляем по мере разработки, преподавателю показываем ЛР как отчёт по этапам.

## 1. Технологии и языки (что учим)

| Технология | Зачем |
|---|---|
| **HTML5** | Семантическая структура страниц (header, nav, main, section, article, footer — не сплошные div) |
| **CSS3** | Стили, адаптив (media queries, flexbox, grid, custom properties/переменные), анимации (transition, @keyframes) |
| **JavaScript (ES6+)** | Интерактив: слайдеры, фильтры, корзина, анимации при скролле, валидация форм, запросы к серверу (fetch) |
| **PHP** | Бэкенд: обработка форм, корзина на сервере, админка, подключение к БД |
| **PostgreSQL** | База данных: товары, пользователи, заказы, статьи |
| **Git / GitHub** | Контроль версий, отслеживание разработки |
| **Lunacy** | Дизайн-макеты перед вёрсткой |

Редактор: **VS Code** (+ расширения: Live Server, Prettier, PHP Intelephense, GitLens, PostgreSQL).

Порядок изучения: HTML → CSS → адаптив → JS → PHP + PostgreSQL.

## 2. Архитектура проекта (папки)

```
chronos-watch-store/
│
├── index.html              # Главная страница
├── catalog.html            # Каталог товаров
├── product.html            # Карточка товара
├── cart.html               # Корзина
├── order.html              # Оформление заказа
├── about.html              # О компании
├── articles.html           # Статьи / блог
├── article.html            # Отдельная статья
├── faq.html                # Вопросы и ответы
├── contacts.html           # Контакты
├── 404.html                # Страница не найдена
│
├── assets/                 # Все статические ресурсы
│   ├── css/
│   │   ├── style.css       # Основной файл стилей
│   │   ├── variables.css   # Переменные: цвета, шрифты, отступы
│   │   └── media.css       # Адаптивные стили (media queries)
│   ├── js/
│   │   ├── main.js         # Главный скрипт (меню, скролл, общее)
│   │   ├── slider.js       # Слайдеры
│   │   ├── catalog.js      # Фильтры и сортировка каталога
│   │   ├── cart.js         # Логика корзины
│   │   ├── product.js      # 3D-эффект, лупа, галерея товара
│   │   └── animations.js   # Анимации появления при скролле
│   ├── img/                # Изображения (желательно /products, /banners, /icons)
│   ├── fonts/              # Шрифты, если подключаем локально
│   └── icons/              # SVG-иконки
│
├── includes/               # PHP-блоки, подключаемые на страницы
│   ├── header.php          # Шапка сайта
│   ├── footer.php          # Подвал
│   └── db.php              # Подключение к PostgreSQL (PDO)
│
├── admin/                  # Админ-панель (добавление товаров, заказы)
├── database/
│   └── chronos.sql         # Дамп базы данных (таблицы + тестовые данные)
├── docs/                   # Отчёты по ЛР, макеты Lunacy, этот план
├── .gitignore              # Что не заливать в GitHub
└── README.md               # Описание проекта
```

Почему так: страницы в корне — понятно и просто для учебного проекта; `assets` собирает всё статическое в одном месте; `includes` убирает повторяющийся код (шапка/подвал пишутся один раз); `database` — чтобы преподаватель мог развернуть БД одним файлом.

## 3. Логика сайта: окна (страницы) и их функции

### 3.1 Главная (index.html)
- Прелоадер (заставка с логотипом при загрузке)
- Шапка: логотип, меню, поиск, иконки корзины/аккаунта (sticky — прилипает при скролле)
- Hero-баннер: полноэкранный, параллакс-фон, кнопка «Смотреть каталог»
- Блок «Категории»: мужские / женские / премиум / коллекционные
- Блок «Хиты продаж»: карусель карточек товаров
- Блок «О компании»: коротко + цифры (лет на рынке, клиентов, брендов)
- Блок «Статьи»: 3 превью статей
- Подписка на рассылку (форма с валидацией)
- Подвал: меню, контакты, соцсети

### 3.2 Каталог (catalog.html)
- Хлебные крошки
- Сайдбар-фильтры: бренд, цена (ползунок), тип механизма, материал, пол
- Сортировка: по цене, по популярности, по новизне
- Сетка карточек товаров + переключение «плитка/список»
- Пагинация или «Показать ещё»
- Карточка: фото, название, цена, кнопка «В корзину», hover-эффект

### 3.3 Карточка товара (product.html)
- Галерея фото (основное + миниатюры, зум по hover — «лупа»)
- Название, цена, характеристики (механизм, корпус, стекло, ремешок, водозащита)
- Выбор количества, кнопка «В корзину», «Купить в 1 клик»
- 3D-tilt эффект карточки при движении мыши
- Вкладки: «Описание» / «Характеристики» / «Отзывы»
- Блок «Похожие товары»
- Хлебные крошки

### 3.4 Корзина (cart.html)
- Список товаров: фото, название, цена, изменение количества, удаление
- Промокод (поле + проверка)
- Итоговая сумма, переход к оформлению
- Пустая корзина — отдельное состояние с кнопкой «К каталогу»
- На этапе JS — localStorage; позже переносим в PHP + PostgreSQL

### 3.5 Оформление заказа (order.html)
- Форма: ФИО, телефон, e-mail, адрес доставки, способ доставки (радиокнопки), способ оплаты, комментарий
- Валидация на JS (проверка телефона, e-mail) и на сервере
- Экран «Заказ оформлен» с номером заказа

### 3.6 О компании (about.html)
- История бренда, фото команды, преимущества, сертификаты

### 3.7 Статьи (articles.html / article.html)
- Список статей (карточки с превью) / отдельная статья
- Контент наполняется из БД на этапе PHP

### 3.8 FAQ (faq.html)
- Аккордеон: вопрос — клик — плавное раскрытие ответа

### 3.9 Контакты (contacts.html)
- Форма обратной связи, карта, адреса магазинов

### 3.10 Личный кабинет (account.html) — этап PHP
- Регистрация/вход, история заказов

### 3.11 Админ-панель (admin/)
- Список товаров, добавление/редактирование/удаление, просмотр заказов

### 3.12 404.html
- Стилизованная страница ошибки с кнопкой «На главную»

## 4. Дизайн-система

### Шрифты
- Заголовки: **Playfair Display** (серифный, «дорогой» характер) или Cormorant Garamond
- Текст/UI: **Inter** или Manrope (чистый, отлично читается)
- Подключение: Google Fonts или локально в `assets/fonts`

### Палитра (CSS-переменные)
```css
:root {
  --color-dark: #111214;      /* основной тёмный (графит) */
  --color-gold: #c8a25a;      /* акцент (латунь/золото) */
  --color-light: #f5f2ec;     /* светлый фон (слоновая кость) */
  --color-gray: #8a8a8a;      /* вторичный текст */
  --color-white: #ffffff;
}
```

### Принципы
- Много «воздуха», крупные фото, минимализм = ощущение премиальности
- Скругления 8–12px, тени мягкие
- Тёмный hero-блок, светлые контентные секции (или наоборот — решаем в Lunacy)

## 5. Анимации и эффекты (что и как реализуем)

| Эффект | Технология | Где |
|---|---|---|
| Прелоадер | CSS @keyframes + JS (скрыть после загрузки) | Вход на сайт |
| Плавное появление блоков при скролле | IntersectionObserver + CSS transition | Все секции |
| Параллакс баннера | JS (scroll-событие, transform: translateY) | Главная |
| 3D-tilt карточки товара | JS (mousemove → rotateX/rotateY) + perspective | Карточка товара |
| Hover карточек (подъём, тень, зум фото) | CSS transition | Каталог, хиты |
| Слайдер/карусель | Swiper.js (библиотека) или свой на JS | Главная, галерея |
| Лупа на фото товара | JS (background-position по координатам мыши) | Карточка товара |
| Аккордеон FAQ | JS (classList.toggle + CSS max-height transition) | FAQ |
| Sticky-шапка | CSS position: sticky | Все страницы |
| Бургер-меню | JS (переключение класса) | Мобильная версия |
| Плавный скролл к якорям | CSS scroll-behavior: smooth | Меню, кнопки |
| Плавное появление модальных окон | CSS opacity/visibility + transition | «Купить в 1 клик», обратный звонок |
| Кастомный курсор (опционально) | JS | Главная |

**Для изучения:** сначала делаем каждый эффект вручную (понимаем механику), библиотеки подключаем только там, где своими силами долго (Swiper).

## 6. Адаптив: размеры и брейкпоинты

### Артборды для Lunacy (макеты)
| Устройство | Размер | Что проектируем |
|---|---|---|
| Телефон (вертикальный) | 360 × 800 | Базовый мобильный |
| Телефон большой | 390 × 844 | iPhone 14/15 Pro |
| Планшет (вертикальный) | 768 × 1024 | iPad |
| Планшет (горизонтальный) | 1024 × 768 | iPad landscape |
| Ноутбук | 1366 × 768 | Базовый десктоп |
| Монитор | 1440 × 900 / 1920 × 1080 | Полная ширина |

### Брейкпоинты в коде (media.css)
```css
/* Мобильные: до 576px — телефоны вертикально */
/* 576–767px — большие телефоны / телефоны горизонтально */
/* 768–991px — планшеты вертикально */
/* 992–1199px — планшеты горизонтально / маленькие ноутбуки */
/* 1200px+ — десктоп */
/* 1400px+ — большие мониторы (контейнер фиксируем в 1320px) */
```

### Три сценария адаптива
1. **Media queries** (`@media (max-width: ...)`), принцип Mobile First или Desktop First — выберем Desktop First (проще для понимания новичку).
2. **Ориентация устройства:** `@media (orientation: landscape)` — на телефоне в горизонтали меню и сетки перестраиваются.
3. **Плавное изменение окна браузера:** все блоки на flexbox/grid, ширина в % и `clamp()`, контейнер с `max-width` — сайт не ломается при любом промежуточном размере.

Практика: проверяем в DevTools (F12 → Toggle Device Toolbar) на ширинах 360, 768, 1024, 1366, 1920.

## 9. Соглашения по коду (чтобы было понятно новичку и «не нейронно»)

1. **Семантика:** каждый тег по смыслу — `<header> <nav> <main> <section> <article> <aside> <footer>`, кнопки — `<button>`, ссылки — `<a>`.
2. **БЭМ-именование:** `block`, `block__element`, `block--modifier` (например `product-card`, `product-card__price`, `product-card--sale`).
3. **Комментарии:** логичные, по делу — перед блоком, не на каждой строке:
```css
/* --- Карточка товара: подъём и тень при наведении --- */
.product-card {
  transition: transform 0.3s ease, box-shadow 0.3s ease;
}
.product-card:hover {
  transform: translateY(-6px);
  box-shadow: 0 12px 24px rgba(0, 0, 0, 0.15);
}
```
```js
// Плавно показываем блок, когда он попадает в зону видимости
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.classList.add('visible');
    }
  });
});
```
4. **Код простой:** без хитрых однострочников и «умных» конструкций; читаемость важнее краткости.
5. **Форматирование:** отступы 2 пробела, один стиль кавычек (Prettier сам следит).
6. **Язык комментариев и коммитов — русский** (учебный проект).
